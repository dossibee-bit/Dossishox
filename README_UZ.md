# DOSSISHOX Telegram Manager — boshlang'ich loyiha

Bu Android Studio uchun boshlang'ich oq rangli ilova maketi. Hozircha Telegram akkauntiga ulanmaydi va xabarlarni o'qimaydi/yubormaydi.

## APK olish (faqat Android telefon bilan)
1. GitHub hisobingizda yangi repository yarating.
2. Ushbu ZIP ichidagi fayllarni repository'ga yuklang.
3. `Actions` bo'limiga o'ting.
4. `Build Android APK` workflow'ini ishga tushiring.
5. Tugagach, `DOSSISHOX-debug-apk` artifact'ini yuklab oling.
6. ZIP ichidagi `app-debug.apk` faylini telefonga o'rnating.

## Keyingi bosqich
Haqiqiy shaxsiy akkaunt ulanishi uchun Telegram MTProto client integratsiyasi, login/2FA oqimi, xavfsiz sessiya saqlash va Android foreground service alohida ishlab chiqilishi kerak. API hash yoki login kodlarini chatga yubormang.
